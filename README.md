# برنامج مالك — تطبيق أندرويد

تطبيق أندرويد يعمل بدون إنترنت، ويضم: ألعاب الانتباه، وحفظ جزء عمّ، ومذاكرة العربي والإنجليزي والرياضيات والألماني.

- النطق يستخدم محرك الصوت في الهاتف (Google TTS)، وهو يدعم العربية والإنجليزية والألمانية.
- نص القرآن مكتوب بالرسم العثماني ولا يُقرأ بالصوت الآلي أبداً؛ التلاوة بصوتك أنت من زر 🎙.
- كل نسخة جديدة موقَّعة بالمفتاح نفسه، فتُثبَّت فوق القديمة وتحتفظ بالنجوم والتقدم والتسجيلات.

## الطريقة الأولى: GitHub (بدون تثبيت أي برنامج)

1. أنشئ مستودعاً **خاصاً (Private)** على github.com وارفع فيه محتوى هذا المجلد كما هو، بما فيه المجلد المخفي `.github`.
2. يبدأ البناء تلقائياً من تبويب **Actions**، ويستغرق نحو 5 دقائق.
3. من صفحة **Releases** في المستودع نزّل الملف `malik.apk` على الهاتف وثبّته.
   أول مرة سيطلب الهاتف السماح بتثبيت التطبيقات من هذا المصدر.

أي تعديل ترفعه لاحقاً يبني نسخة جديدة تلقائياً.

## الطريقة الثانية: Android Studio

1. افتح المجلد في Android Studio.
2. من القائمة: **Build ← Build App Bundle(s) / APK(s) ← Build APK(s)**.
3. الملف الناتج في `app/build/outputs/apk/`.

## تحديث محتوى التطبيق

كل محتوى التطبيق في ملف واحد: `app/src/main/assets/www/index.html`.

## ملاحظة عن مفتاح التوقيع

الملف `app/malik.keystore` هو مفتاح توقيع التطبيق. أبقِ المستودع خاصاً ولا تحذف هذا الملف،
لأن تغيير المفتاح يجبرك على حذف التطبيق القديم قبل تثبيت الجديد، فيضيع تقدم مالك.
